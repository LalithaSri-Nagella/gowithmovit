# MOVIT

### Move smarter. Wait less.

MOVIT is a smart public transportation assistant designed to help users find and choose the most suitable bus for their journey.

## Features

- Find available buses for the selected route
- Compare buses based on arrival time and journey conditions
- Choose the optimal bus
- View upcoming buses for up to one hour
- Get a notification when the selected bus is approaching
- Simple, spacious dark-themed interface

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Project

Built as a student project to improve the public transportation experience.
