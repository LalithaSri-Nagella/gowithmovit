# MOVIT

**Move Smarter. Wait Less.**

MOVIT is a smart public transport web application made to help people choose a better bus instead of just taking the next bus.

The idea is simple: when more than one bus is available, the user can check the arrival time, delay, crowding and route information and then choose the bus that is more suitable.

## What MOVIT Does

- Shows buses available in the next 60 minutes
- Shows estimated arrival time
- Shows delay information
- Shows crowding condition
- Shows route/status information
- Gives a suggested bus
- Allows passengers to report their travel experience

## How It Works

```text
Select From
     ↓
Select To
     ↓
Search for buses
     ↓
See upcoming buses
     ↓
Compare buses
     ↓
Choose a suitable bus
```

## Why We Made It

Usually, passengers just wait for the next bus and take it. But sometimes the next bus can be delayed or very crowded, while another bus may arrive shortly after and be a better option.

MOVIT tries to make this choice easier by showing the important information in one place.

## Main Parts of the Project

**Bus Search**  
Users select where they are going and search for available buses.

**Next 60 Minutes**  
Upcoming buses are shown so the user can compare them.

**Bus Details**  
Information like arrival, delay, crowding and route condition is shown.

**Recommendation**  
MOVIT highlights a bus that looks more suitable based on the available information.

**Transport Status**  
Users can check general transport updates.

**Passenger Report**  
Passengers can share information such as crowding, delay, breakdowns or route changes.

## Project Status

This is a **prototype / academic project**. The current version uses demo or simulated transport information. It is not presented as a fully live GPS tracking system.
